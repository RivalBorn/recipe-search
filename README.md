# Recipe Search App

A completed React + Vite recipe finder app. Users can search recipes by name, ingredient, category, difficulty, or tag, then view ingredients and instructions for the selected recipe.

## Features

- Recipe search by keyword
- Category filter
- Difficulty filter
- Max cooking-time slider
- Recipe detail panel with ingredients and instructions
- Responsive layout for desktop and mobile
- Built with React and Vite

## Run the project

```bash
npm install
npm run dev
```

## Build for production

```bash
npm run build
```
